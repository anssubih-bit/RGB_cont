# Strip Control

A controller app for ELK-BLEDOM / ELK-BLEDDM / LEDBLE Bluetooth LED strips (the ones that ship with LotusLanternX).

**Open the app:** https://anssubih-bit.github.io/RGB_cont/

- On a computer or Android: open the link in Chrome or Edge and press Connect.
- On iPhone: open the link in the free **Bluefy** browser (Safari can't use Bluetooth from web pages).
- Close LotusLanternX first. The strip only accepts one connection at a time.

Features: color wheel, warm/cool white, saved colors, 22 built-in modes with speed, custom color modes,
music mode (microphone), scenes, sleep timer and on/off schedule.

`ios/` holds a basic native SwiftUI version (build with Xcode on a Mac, see `ios/README.md`).
